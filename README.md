# Reester: Family Restaurant Website

A small static website for a family restaurant. It was one of my first web projects, built to practise HTML, CSS and JavaScript.

## Features

- Restaurant landing page with dish images and a menu section
- **Order** buttons that show a confirmation message for the chosen dish
- Contact form with simple validation (name and email required, email format check)
- Custom Google Font (Young Serif)

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

No build step is needed.

```bash
git clone https://github.com/BALASUBRAMANIYAN-S/project_of_Restaurants.git
cd project_of_Restaurants
```

Open `index.html` in a browser.
